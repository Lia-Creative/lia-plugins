# squeaks

Scaffold and drive **deliberately-rough, copy-first lo-fi prototypes** with Claude Code.

Squeaks keeps the thinking ahead of the polish: a clickable wireframe you can navigate, with intentionally unfinished styling (Comic Neue, monochrome, 2px borders) so nobody mistakes it for a final design.

## Commands

- `/squeaks:new <name>` — scaffold a fresh prototype from [`Lia-Creative/squeaks`](https://github.com/Lia-Creative/squeaks), install deps, and start the dev server on `http://localhost:5173`.

## Skill

The `squeaks` skill encodes the methodology (copy-first, ASCII wireframes, versioned routes, rough-on-purpose) and loads automatically when you're working inside a Squeaks prototype.

## When to use

- **Idea or flow not shaped yet →** Squeaks.
- **Real component in an existing product repo →** [`design-and-refine`](https://github.com/Lia-Creative/design-plugin) (the hi-fi half of the pair, also in the `lia-plugins` marketplace).

Part of the [`lia-plugins`](https://github.com/Lia-Creative/lia-plugins) marketplace.
