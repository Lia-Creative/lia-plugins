## What shipped — the skill (v0.3.0)

Canonical: `_meta/skills/ticket-builder/SKILL.md`. The review landed in two passes.

**v0.2.0 — correctness.** The skill had gone stale in ~3 weeks. Fixed: it knew one Linear team when there are now two (`Lia`/Creative + `Lia Build`/software); the post-2026-06-19 workflows (retired `Done Ready`, restored `In Progress`); and Step 0 now **self-heals** by pointing at `CLAUDE.md` as the source of truth with a dated cache. Added the four founder calls — estimates skipped, a deliberate priority on every ticket, the doc-vs-ticket line, and a principles-first preamble — plus the explicit LIA-281 seam.

**v0.3.0 — readability.** Triggered by CQ's feedback that the first dogfood output was "agent-mush." Changes:

- **Epics lead with JTBD / User / Success / Why** — a job for a named person, and never a list of their own sub-features (the sub-issues are the list).
- **Two ticket shapes, match the project's siblings.** Shape A = User story / Why it matters / Acceptance criteria / Scope (Lia Build features). Shape B = the six-part Goal/In scope/DoD/Review beat/Creative injection/Depends on (Lia Creative workstreams). Don't force one template.
- **Plain titles, no numbers** — priority + blocked-by drive order.
- **Links live in Linear's relation fields, not in the prose.**
- Added principle 5 (human-first, not spec-first) and an assignee rule (build tickets → the builder).

## Gotchas worth remembering

- **Skills go stale fast.** This one was ~3 weeks old with wrong team/status coordinates. v0.3.0 defers to `CLAUDE.md` (dated cache) so it self-heals — re-confirm if the cache date is old.
- **Format varies by project — match siblings, don't force one template.** File Runner uses User-story/Acceptance-criteria; Foundations uses the six-part.
- **Vault copy ≠ installed copy.** Editing the vault `SKILL.md` updates the canonical doc; the *installed* plugin copy that auto-triggers is a build artifact rebuilt from it. They matched on CQ's machine; Dan's is separate.
- **Drive sync conflicts bite.** A stray `_meta/index 2.md` had silently dropped a real wiki row (`Wiki/products/musician-os.md`); caught on a pre-delete diff and restored before the file was removed.
