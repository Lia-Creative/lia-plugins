# Proto audience profiles — cold-start prompt (thin data)

Use when the client has little or no customer data but informed CS / marketing / sales people, or only the client's own assumptions. Generates differentiated archetypes to seed Stage 1, with every claim's confidence flagged so nothing speculative passes as known. Deepen into full profiles as real data arrives.

## The prompt

> I'm an experience designer. Help me generate user profiles for a product. I'll provide foundational context about the business, product, users, market, and constraints. Based on it:
>
> 1. Generate **[X] distinct user archetypes** with clear **behavioural** differentiation (not just demographic variation).
> 2. For each archetype provide: name + short descriptor, primary goal, key frustration, context of use, decision-making style, technical proficiency, and what differentiates them **behaviourally** from the others.
> 3. Flag which aspects of each archetype are **grounded in well-established industry patterns** vs **inferred from the client's assumptions** vs **speculative**.
> 4. After the archetypes, suggest user types I may be missing — edge cases, underserved segments, reluctant users, or people affected by the product who aren't the primary user.

## Context to gather (fill before running)

**The business**
- What the organisation does
- Business model (B2B / B2C / B2B2C / marketplace / other)
- Revenue model and what "a good customer" means commercially

**The product**
- What it is and the core job it does
- Typical technical proficiency of users (power / comfortable / reluctant / assisted)
- Self-selecting or mandated use
- What the client *believes* motivates users to start — *label as client assumption*
- What the client *believes* makes users stop or switch — *label as client assumption*
- Seasonal / cyclical / event-driven usage (or unknown)

**Market & competition**
- Direct competitors
- Indirect competitors / alternatives (including manual workarounds and "doing nothing")
- What the client believes differentiates them — *label as client assumption*
- Known industry research / benchmarks / public data (or none)

**Existing knowledge & data**
- Any prior research, even informal (or none)
- SMEs who interact with customers regularly, and their roles (or none)
- Available analytics / behavioural data (or none)
- Existing personas, segments, journey maps, service blueprints (or none)
- Any commercial segmentation already in use

## Output → next step

Treat every output as a **proto-profile**: a hypothesis about who the user is, not a finding. Use it to establish product-development hypotheses and to direct the first real research. As data lands, promote the strongest proto-profiles into full Stage 1 profiles + Stage 2 journey maps, replacing "speculative/inferred" tags with grounded data.
